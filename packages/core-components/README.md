# Commerce Layer Core Components

A collection of low-level async functions that wrap the [Commerce Layer SDK](https://github.com/commercelayer/commercelayer-sdk), leveraging [Commerce Layer API](https://docs.commercelayer.io/api/).

It is the foundation layer used internally by `@commercelayer/react-hooks-components` and by `@commercelayer/react-components`. You can also use it directly to fetch or mutate Commerce Layer resources outside of a React component — it has no React dependency and runs anywhere JavaScript does, including Node.js, edge functions and plain scripts.

## Installation

```bash
npm install @commercelayer/core-components
```

## Documentation

Full reference, with the complete list of exported functions and examples, lives in the [Core package](https://commercelayer.github.io/commercelayer-react-components/?path=/docs/getting-started-core-package--docs) page of the interactive documentation.
