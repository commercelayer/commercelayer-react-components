# Commerce Layer React Hooks Components

A collection of React hooks for fetching and mutating Commerce Layer resources, leveraging [Commerce Layer API](https://docs.commercelayer.io/api/).

Built on [SWR](https://swr.vercel.app) over `@commercelayer/core-components`, the hooks give you caching, request deduplication and loading states, so you can build your own UI without reaching for the components in `@commercelayer/react-components`.

## Installation

```bash
npm install @commercelayer/react-hooks-components
```

Requires React 19 or later as a peer dependency.

## Documentation

Full reference, with the complete list of hooks and examples, lives in the [Hooks package](https://commercelayer.github.io/commercelayer-react-components/?path=/docs/getting-started-hooks-package--docs) page of the interactive documentation.
